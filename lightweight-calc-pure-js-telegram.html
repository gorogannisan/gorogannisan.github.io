Зачем тащить 500 Кб бандла React на сайт оптовой базы пиломатериалов? История о том, как отказ от тяжелых фреймворков в пользу чистого JS, мгновенный пересчет кубов в штуки и прямой экспорт корзины в Telegram утроили конверсию в реальные оптовые заказы.

  1. 01 Ввод параметров Выбор породы, сечения доски (50х150х6000) и объема
  2. 02 Мгновенный расчет Пересчет кубов в штуки, расчет веса и скидки без задержек
  3. 03 Спецификация Формирование точного листа заказа в памяти браузера
  4. 04 Telegram Handoff Отправка заявки напрямую боту менеджеров в 1 клик

Контекст: почему стройка не прощает тяжелые SPA

Покупатели пиломатериалов — это прорабы, бригадиры и снабженцы, которые чаще всего оформляют заказ прямо на объекте или в дороге: слабый 3G интернет, бюджетный Android-смартфон с забитой памятью, яркое солнце на экране. Если страница открывается дольше 3 секунд, прораб нажимает «Назад» и звонит следующему номеру из поиска.

Вторая проблема — математика отрасли: дерево продается и отгружается в кубических метрах, но строителям для каркаса или кровли нужны конкретные штуки досок определенного сечения и длины. На большинстве сайтов клиенту предлагали самостоятельно высчитывать формулы на калькуляторе или оставлять «заявку на обратный звонок».

Zero-framework архитектура: 24 Кб против 600 Кб React

Я сознательно отказался от React, Next.js, Vue и тяжелых библиотек UI-компонентов. Вся кодовая база проекта «Лес Куб» уместилась в: - Семантический HTML5 с серверным рендером; - Легковесный модульный CSS на системных переменных; - Чистый JavaScript без единого стороннего npm-пакета (общий вес скрипта — 24 Кб в gzip).

Математика пиломатериалов: расчет кубов на лету

Калькулятор мгновенно связывает кубы, штуки, вес и ступенчатую скидку (от 10 м³ и от 30 м³). При изменении любого инпута все связанные величины пересчитываются синхронно без лагов.

Vanilla JS Engine 
// Реактивное ядро калькулятора без сторонних библиотек
function calculateLumber(thickness, width, length, count) {
  const pieceVolume = (thickness * width * length) / 1e9; // объем одной штуки в м³
  const totalVolume = pieceVolume * count;
  const piecesInCube = pieceVolume > 0 ? (1 / pieceVolume).toFixed(1) : 0;
  
  // Расчет веса (сосна естественной влажности ~ 750 кг/м³)
  const weightKg = Math.round(totalVolume * 750);
  
  return {
    pieceVolume: pieceVolume.toFixed(4),
    totalVolume: totalVolume.toFixed(3),
    piecesInCube: piecesInCube,
    weightKg: weightKg
  };
}

Telegram Handoff: заказ в один клик без капчи

Традиционные интернет-магазины заставляют пользователя регистрироваться, подтверждать email и вводить длинные адреса. В B2B-строительстве это убивает сделку.

Лес Куб Web Client Engine
  1. Мгновенный выбор позиций Калькулятор сохраняет набранную корзину в LocalStorage
  2. Генерация спецификации Скрипт формирует красивый Markdown-текст с артикулами и ценами
  3. Webhook в Telegram-бот Менеджеры оптового отдела получают пуш с номером телефона покупателя
  4. Ответ за 2 минуты Менеджер звонит клиенту, когда расчет уже перед глазами

Telegram Webhook Sender 
async function sendOrderToTelegram(cartItems, clientPhone) {
  const text = [
    🌲 Новый заказ из калькулятора Лес Куб,
    📞 Телефон: \${clientPhone}\,
    --------------------------------,
    ...cartItems.map((item, idx) => 
      ${idx + 1}. ${item.name} (${item.dimensions}) — ${item.count} шт (${item.volume} м³)
    ),
    --------------------------------,
    💰 Итого: ${cartItems.reduce((acc, i) => acc + i.price, 0)} ₽
  ].join('\n');



return fetch('/api/telegram-order', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ message: text })
  });
}
